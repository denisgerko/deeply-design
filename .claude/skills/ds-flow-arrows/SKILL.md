# Стрелки флоу

`figma.createConnector` в design-файле недоступен. Коннектор делается **клоном шаблона**: один раз пользователь
вставляет любой коннектор (из FigJam или community-файла «Native Figma Flow Arrows») в рабочий файл, называет его
`Connector template (hidden)` и скрывает. Его id — `figma.config.json` → `profile.flow.connectorTemplate`.
Векторные стрелки не рисовать.

## Стиль

- Линия `ELBOWED`, начало без шапки, конец `ARROW_LINES`, толщина 2. Цвета и шрифт — `profile.flow`
  (по умолчанию роли `accent`, `textSecondary`, `screenBg`). Text style к подписи коннектора не привязывается
  (ограничение API) — допустимое исключение.
- Коннекторы лежат **за** экранами. Шаблон остаётся скрытым.
- Вход во флоу — заметка `Flow Start` слева (триггер входа + общие правила фичи + «тексты черновые»).
  Выход на экраны вне файла — заметка `Flow End — <Куда>` справа. Заметки — `ds-flow-arrows/flow-note` (до стрелок).

## Как

1. Экраны флоу — в одной секции, слева направо по ходу сценария; ветки и ошибки — рядом ниже.
2. Карта переходов: откуда → куда, магниты (`TOP / BOTTOM / LEFT / RIGHT`) или точка `[x, y]` на фрейме
   (несколько стрелок с одной стороны), подпись — действие (`Tap`, `Next`, `Submit`, `Skip`, `Error`).
3. `ds-flow-arrows/connect SECTION_ID=… F='{"a":"1:2",…}' LINKS='[["a","RIGHT","b","LEFT","Next"],…]'`.
4. Скриншот секции: подписи не перекрываются, линии не идут поверх экранов. Спряталась подпись — переразвести
   магниты (ветки через BOTTOM).
5. **Тёмная копия** (если dark есть в продукте): клон секции целиком — эндпоинты ремапятся на клоны
   (`ds-reference-screen/dark-clone SECTION_ID=…`).
6. `figma.config.json` → `flows.<Фича>`: section, dark, экраны, вход, выход.
