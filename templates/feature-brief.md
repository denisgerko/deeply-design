# Формат ТЗ для Claude (макеты новой фичи)

Одна задача — одно сообщение. Поля, которых нет, можно пропустить: Claude подставит дефолт и вынесет это в вопросы.
Обязательные отмечены *. Скриншоты прикладывать с подписью-номером («1 — экран оплаты»).
ТЗ свободным текстом тоже подходит — Claude сам разложит его по этим полям.

## Новая фича

```
ЗАДАЧА: новая фича
НАЗВАНИЕ*:
ЗАЧЕМ: 1–2 предложения (цель пользователя / бизнеса)

ВХОД*: откуда пользователь попадает (экран, кнопка, событие, push)
ВЫХОД*: куда уходит в конце; что при закрытии / Skip

ЭКРАНЫ* (в порядке флоу):
1. <Название> — <полноэкранный | шторка | page sheet | модалка | меню | тост>
   На экране: …
   Главное действие: …
   Состояния: пусто · выбрано · ввод (клавиатура) · загрузка · ошибка · лимит · успех · скролл · другое
2. …

ПЕРЕИСПОЛЬЗУЕМ: экраны / компоненты продукта (ссылки с node-id)
НОВОЕ: чего в продукте нет

ЛОГИКА И ДАННЫЕ:
- что приходит из CMS / бэкенда; минимум и максимум (число опций, длина текста)
- когда кнопка активна, лимиты, валидация, ветвления

ТЕКСТЫ: финальные (списком ниже) | черновые
РЕФЕРЕНСЫ: ссылки Figma с node-id, скриншоты, тикет
ПЛАТФОРМА / РАЗМЕРЫ: как в продукте (по умолчанию) | доп. размеры; тёмная тема — как в продукте
НЕ ДЕЛАЕМ:
ОТКРЫТЫЕ ВОПРОСЫ: что продукт ещё не решил
```

## Правка

```
ЗАДАЧА: правка
ГДЕ*: ссылка на узел (node-id) или название экрана / компонента
ЧТО НЕ ТАК*: …
КАК ДОЛЖНО БЫТЬ: … (или «как в продукте <ссылка>»)
ОБЛАСТЬ: только здесь | везде, где используется
```

## Пример

```
ЗАДАЧА: новая фича
НАЗВАНИЕ: Cancel Survey — опрос после отмены триала
ЗАЧЕМ: узнать причины отмены и вернуть на пейволл

ВХОД: следующий запуск после отключения автопродления
ВЫХОД: View Plans → существующий пейволл; Close → главная; Skip на каждом экране → следующий шаг

ЭКРАНЫ:
1. Вопрос 1 — полноэкранный
   На экране: заголовок, 4–8 вариантов (CMS), Continue
   Главное действие: Continue (активна после выбора)
   Состояния: пусто · выбрано · лимит (3 из 8) · Other пусто · Other заполнено + клавиатура
2. Вопрос 2 — то же, другая CTA
3. Спасибо — полноэкранный
   Главное действие: View Plans; вторичное — Close

ПЕРЕИСПОЛЬЗУЕМ: мультиселект онбординга <ссылка>
НОВОЕ: поле под опцией Other (однострочное, до 200 символов)
ЛОГИКА И ДАННЫЕ: число опций из CMS — макет держит 4 и 8 со скроллом
ТЕКСТЫ: черновые EN
НЕ ДЕЛАЕМ: ошибку отправки
```

## Что Claude делает с пропусками

- Не хватает того, что меняет структуру (тип экрана, вход / выход), — спросит до начала.
- Остальное — разумный дефолт (платформа и размеры продукта, light + dark если есть в продукте, черновые тексты),
  список «решено по умолчанию» в отчёте.
